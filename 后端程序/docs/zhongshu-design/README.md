## 代码区域约定

- 业务模块：`yudao-module-identity`、`yudao-module-design`、`yudao-module-commerce`、`yudao-module-ai-orchestration`（命名映射见 T00 登记 §5）。
- 四个业务模块之间**零 Maven 依赖**；跨模块只经 Application Service/领域事件/Port 交接。
- 数据库迁移：P1B 起由 Flyway 管理，目录与命名在 P1B 首提交冻结。
- 提交协议：中文 Lore 提交，写明 `Tested`、`Not-tested`、风险与回滚；迁移先独立提交。
