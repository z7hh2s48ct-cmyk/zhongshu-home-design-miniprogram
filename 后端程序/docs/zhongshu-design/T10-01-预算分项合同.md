# T10-01 预算分项合同

> 版本：ITEMIZED_V1，2026-09-08。上游：[已确认最终方案](../../../项目文档/T10-预算模块最终修改方案-V1.0.md)。
> 此增补只替代旧架构 §6.8 的新建分项预算口径；旧区间接口和已存数据继续兼容。参数、目录/地区价、分项生成/保存/历史、项目补项修订及最终报价已有本地实现和测试，均不表示已部署。

## 1. 最小实现约束

- 不新增 Maven/npm 运行时依赖，复用 Spring JDBC、Jackson、现有事务/审计/身份端口及 JUnit。
- 不引入公式解释器、通用工作流引擎或新的服务层级。计价只执行十进制单价×数量。
- 项目参数沿用 `design_requirement_snapshot.inputs`，在其中增加结构化 `budgetInputs`；不另建参数服务或跨业务模块依赖。
- 预算目录、地区价、预算修订和报价分别建最少必要表；复用budget_estimate为主记录，保存状态直接放原表，不另建预算主表或多用户收藏系统。
- 原迁移不改写。新增分项数据存预算修订/明细，旧预算不回填虚构明细。

## 2. 字段与范围

ID一律十进制字符串，后端转换为正long。接口金额为整数分（JSON整数），不以万元显示文本回传。工程量为十进制字符串，拒绝NaN、Infinity、科学计数法和非法文本。

| 字段 | 类型/范围 | 缺失规则 |
|---|---|---|
| regionCode | 1～32字符，`[A-Za-z0-9_-]+` | 创建完整测算必须有 |
| footprintArea / buildingArea / roofArea | 正十进制，≤1,000,000㎡，最多4位小数 | 不填不得当0或互相代用 |
| faceWidth / depth | 正十进制，≤1,000米，最多4位小数 | 仅两者齐备才推导占地面积 |
| floorCount | 1～20整数 | 只有占地面积且层数有效才推导建筑面积 |
| quantities | 白名单计价子项编码→数量，长度/面积≤1,000,000，个/套/户/项≤100,000 | 缺量返回待补，不能静默默认 |
| unitPriceCents | 0～100,000,000整数分 | null=缺价；0仅允许明确免费且有原因 |
| lineAmountCents / totals / finalPriceCents | 0～10,000,000,000整数分 | 不完整预算的totalCents为null，已有金额在pricedSubtotalCents |
| quantity | 最多4位小数；不可分单位必须整数，必须>0 | 0不是未选中，不参与计算应明确排除 |
| name / publicName | 1～100字符 | 修订保存时快照，之后改名不影响历史 |
| reason / internalNote | 原因1～500字符；备注≤500字符 | 免费/排除/专用价/补项变更/报价调整有相应原因；不下发App |
| idempotencyKey | 1～64字符 | 写操作由调用端对同一逻辑操作复用 |
| expectedVersion | ≥1整数 | 更新预算/价格草稿/报价必传，过期冲突 |
| pageNo / pageSize | ≥1 / 1～100 | 默认1/20；列表分页 |

上述上限是防误输入/溢出的技术边界，不代表公司承接项目的限制。边界常量集中维护，变更时同时更新合同与测试。

单位枚举：SQM=㎡、METER=米、PIECE=个、SET=套、HOUSEHOLD=户、ITEM=项。数量来源：FOOTPRINT_AREA、BUILDING_AREA、ROOF_AREA、WINDOW_AREA、PROJECT_QUANTITY、FIXED_ONE。WINDOW_AREA仅执行有来源的建筑面积×0.25；计算行金额时不能再乘系数。FIXED_ONE只用于明确固定的防雷/保险/固定费用，不默认为所有未知工程量填1。

参数来源：PROJECT、DERIVED、USER_OVERRIDE、ADMIN_OVERRIDE，保存原值及当前值。有独立建筑面积时，面积/层数修改产生不一致须提示复核，不覆写其原值。

### 2.1 T10-03 已实现的项目参数合同

复用项目创建的 `requirementInputs.budgetInputs` 与立面任务配置中的 `budgetInputs`，存入原 `design_requirement_snapshot.inputs`。新嵌套字段严格校验，原设计字段不重解释；预算字段非法时在项目写入或创建收费任务前拒绝。

- 新面积、长度及工程量必须传十进制字符串，层数为整数值；拒绝未知字段、价格字段及超范围/超精度值。省略表示该次快照不更新该字段；显式 `null` 表示清空。`quantities` 是整体字段，更新时应携带当前完整工程量集合。
- 读取旧快照仅接受已存的结构化同名字段；兼容已观察到的 `floor="两层"`，不从 prompt、静态页面文案或图片提取尺寸。旧值不合法按缺失处理。
- 按 `input_version, id` 合并需求快照；指定 `resultVersionId` 时只读该版本创建时及之前的需求快照，版本 `config_snapshot` 中的显式预算字段优先。项目/版本必须属于当前用户且未删除。此处依赖既有需求快照追加写入约定，不重写旧快照。
- 占地面积缺失且面宽、进深齐全才推导；建筑面积实际值优先，否则由占地×层数推导。推导面积 `HALF_UP` 至4位小数，超界或舍入为0仍缺失并告警；屋顶面积不推导。
- `BudgetInputs.resolve` 接受独立覆盖集合，仅允许地区、占地、层数、屋顶面积；保留原导入集合，空覆盖集合恢复该次导入值，显式清空占地后不再次从尺寸补回。实际建筑面积不被覆盖，冲突返回 `BUILDING_AREA_REVIEW_REQUIRED`；后续计价须将其作为待复核条件，不可静默形成完整报价。
- 覆盖/恢复使用同一纯逻辑；T10-06 将原值、现值、来源写入预算修订，T10-12 接入按会话/项目/方案隔离的本机草稿与返回恢复。未增加“修改原设计项目”的预算接口。

内部工程量键：`DOOR_HOUSEHOLDS`（户）、`WINDOW_AREA`（㎡）、`WALL_PAINT_AREA`（核定等效㎡）、`CULTURE_STONE_LENGTH`（米）、`LIGHTING_WASHER_LENGTH`（米）、`LIGHTING_STRIP_LENGTH`（米）、`LIGHTING_WALL_LAMP_COUNT`（个）、`WATERPROOF_AREA`（天沟/露台㎡）、`INSULATED_WATERPROOF_AREA`（平顶施工㎡）。个/户必须整数；缺失不填1。窗面积的0.25转换留在T10-05按选项数量来源执行，不在参数导入阶段猜测或重复计算。

`GET /app-api/design/v1/design-projects/{projectId}/budget-inputs?resultVersionId=…` 返回 CommonResult 包装，data 固定包含：

| 字段 | 当前响应语义 |
|---|---|
| projectId / resultVersionId | 正long十进制字符串；未指定版本为null |
| requirementSnapshotIds | 参与导入的既有需求快照ID字符串列表；非完整变更审计 |
| importedValues | 只含已具备的regionCode、footprintArea、floorCount、buildingArea、roofArea；不返回缺失值为0 |
| sources | 上述已具备字段对应PROJECT或DERIVED |
| missingFields | 上述5个字段中尚缺失的字段名，不等于完整预算缺项清单 |
| warnings | 实际/推导面积不一致及推导超界告警 |

工程量只供内部计价使用，不放入此DTO；已有方案列表的 `configSnapshot` 也过滤根层 `quantities` 和嵌套预算私有字段，保留原设计配置及数据库原快照。小程序通过原HTTP层导入，并将公开字段白名单投影到页面与草稿。

## 4. 分项、自定义项与金额合同

计算输入为经过服务端查价/授权的内部行：lineId、itemId、itemCode、category、publicName、optionId、optionLabel、unit、quantity、unitPriceCents、freeReason、excludedReason、source。source为STANDARD、CUSTOM_TEMPLATE或PROJECT_CUSTOM。

- 同名不同ID不合并；同一lineId拒绝重复。自定义项只归BODY或EXTERIOR。
- 明细计算状态为PRICED、MISSING_PRICE、MISSING_QUANTITY、MISSING_BOTH、EXCLUDED。排除行无金额，原因必填；缺价不是免费。
- `amountCents = HALF_UP(unitPriceCents × quantity, 0)`，逐行舍入后汇总；空明细或有缺失行的预算为INCOMPLETE。明确排除不当作待补项。
- 主体/外装小计及pricedSubtotalCents汇总已计价行。只有COMPLETE时totalCents等于小计；否则totalCents=null。缺失标准配置在服务端创建明确的待补行，不以空列表冒充完整预算。
- 报价必须引用COMPLETE预算版本；finalPriceCents或adjustmentCents二选一；系统测算值不改写；免费/排除原因与报价调整原因分开。
- 模板自定义项默认仅管理员可选；公开下拉需要显式开启且配置完整。项目临时项不能外泄到其他项目。固定金额采用ITEM×1。负数优惠仅通过报价差额。

## 5. 数据模型与状态

新表：budget_region、budget_item、budget_option、budget_item_price、budget_revision、budget_line、budget_quote。budget_estimate新增model、saved、current_revision及幂等字段，旧行默认LEGACY_RANGE；旧区间列保留，分项行允许其为空。budget_rule_version继续专用于旧区间，不强行塞入新的选项模型。

预算主记录保存所属项目/用户、原方案版本、当前修订号及saved标志。修订保存不可变输入快照、分项快照和合计；每次后台补项产生新修订。报价保存绑定修订、最终价、差额、原因、状态、版本和发布人/时间。审计复用既有审计端口，不能另建通用审计平台。

价格：DRAFT→PUBLISHED→停用，不原地改动已发布价格值；有效区间左闭右开，同地区同选项不可重叠。采用既有事务与行锁串行化发布，无额外PG扩展依赖。

报价：DRAFT→PUBLISHED→WITHDRAWN；改价生成新版本。新增预算修订后，基于旧修订的未发布报价必须重新核对。已有发布快照不变。

幂等范围为操作者+操作种类+幂等键，必须包含请求指纹；同键异体返回IDEMPOTENCY_KEY_REUSED。修订、明细、合计与审计同事务。并发写锁预算主记录，核对expectedVersion，不以最后写入覆盖前人改动。

## 6. API合同

所有接口继续返回CommonResult。下表相对路径以/design/v1为前缀。保留已有budget-estimates读取路径；旧创建入口仍处理原请求，新增明确的分项创建子路径，不因宽松字段反序列化误把新请求当旧请求。

| 端 / 方法 / 相对路径 | 请求要点 | 响应/约束 |
|---|---|---|
| App GET /design-projects/{projectId}/budget-inputs | resultVersionId可选，须属本项目 | public参数及来源、缺失字段，不含内部备注 |
| App GET /budget/regions | 启用地区 | code、name |
| App GET /budget/options?regionCode= | 地区 | itemId/code/category/name/optionId/label/选择组/可用状态，不含价格和转换参数 |
| App POST /design-projects/{projectId}/budget-estimates/itemized | resultVersionId、允许的inputOverrides、optionIds、Idempotency-Key请求头 | 新预算ID、修订ID、公开结果；项目/选项/金额服务端校验 |
| App GET /budget-estimates/{budgetId} | 复用原详情路径；revisionId可选，默认该记录用户可读版本 | 公开预算，不自动读取管理员未发布草稿 |
| App POST /budget-estimates/{budgetId}/save | Idempotency-Key请求头 | saved=true，不重复测算 |
| App GET /design-projects/{projectId}/budget-estimates | 复用原列表路径，新增可选savedOnly/cursor/limit；无新参数保留旧列表形状 | 旧区间与新预算共享主表；游标分页结果形状单独明确 |
| App GET /design-projects/{projectId}/budget-quotes | 项目ID | 仅当前用户项目已发布/撤回状态的公开版本列表 |
| App GET /design-projects/{projectId}/budget-quotes/{quoteId} | 项目ID、报价ID | 仅当前用户项目的指定已发布/撤回公开版本 |
| Admin GET/POST/PATCH /regions | 地区编辑 | 受配置权限保护 |
| Admin GET/POST/PATCH /items、/options | 模板/选项及数量口径 | 核心编码不可删改，版本校验 |

| Admin GET /estimates；GET /estimates/{id} | 分页筛选/修订ID | 内部参数、数量、价格、行金额、来源 |
| Admin POST /estimates/{id}/revisions | expectedVersion、明确的增改删行、原因、幂等键 | 原子生成新修订，旧版保留 |
| Admin POST /estimates/{id}/items/{lineId}/template | 名称、编码、原因 | 创建目录草稿，不复制项目专用价为已发布地区价 |
| Admin POST /estimates/{id}/quotes | revisionId、expectedVersion、最终价或差额、原因、幂等键 | 新报价草稿，完整性校验 |
| Admin POST /quotes/{id}/publish、/withdraw | expectedVersion、原因、幂等键 | 原子发布/撤回及审计 |
