# 芋道 ruoyi-vue-pro（yudao）技术架构分析

> 仓库：`https://github.com/YunaiV/ruoyi-vue-pro`
> 本地路径：`~/Documents/github/ruoyi-vue-pro`
> 克隆方式：浅克隆（`--depth 1`，master 分支）
> 基础包：`cn.iocoder.boot` / `cn.iocoder.yudao`

---

## 0. 一句话结论

**这是「单体版（monolith）」的芋道 yudao**，不是微服务版。整个后端是一个 `yudao-server` 进程（FatJar，端口 48080），通过 Maven 多模块拆分业务；前端是多套 Vue 管理后台（Vue3/ Vue2 / Vben / uni-app）。**没有**网关、Nacos、Feign、Seata、Sentinel、Elasticsearch —— 这些都只在独立的微服务仓库 `yudao-cloud` 里。

## 2. Maven 模块划分（19 个）

```
yudao (父 pom, packaging=pom)
├── yudao-dependencies   # 版本 BOM 中枢（统一管理全部依赖版本）
├── yudao-framework      # 通用组件聚合（15 个 starter 子模块）
├── yudao-server         # 聚合启动层（空壳容器，打包 FatJar，48080）
└── yudao-module-*       # 业务模块
```

### 2.1 基座（所有模块共用）
- **yudao-dependencies**：纯 BOM，`<dependencyManagement>` 统一所有依赖版本。
- **yudao-framework**：15 个 `yudao-spring-boot-starter-*` 子模块
  - `web`（JSON / XSS / 脱敏 / 字段加密 / API 日志 / Swagger-Knife4j）
  - `security` + `operatelog`（Spring Security 集成 + 操作日志）
  - `redis` / `mybatis`（MP + 多数据源 + 数据翻译 easy-trans）
  - `job`（Quartz）/ `mq`（Redis MQ / RabbitMQ）
  - `protection`（限流 / 幂等 / 分布式锁 lock4j / 签名防篡改）
  - `monitor`（SkyWalking / OTel 链路）/ `excel` / `websocket` / `test`
  - `biz-tenant`（多租户）/ `biz-data-permission`（数据权限）/ `biz-ip`（ip2region）

### 2.2 业务模块职责
| 模块 | 职责 | 子模块拆分 |
|---|---|---|
| system | 用户/部门/岗位/角色/菜单/权限/字典/租户/短信/邮件/OAuth2/社交登录/操作日志 | 单一 |
| infra | 代码生成器 / 文件 / 配置 / Redis / 邮件 / Job / MQ / API 日志 / WebSocket | 单一 |

| iot | 物联网 | **3 子模块**：iot-core / iot-biz / iot-gateway(Netty/MQTT/CoAP/Modbus) |

### 2.3 激活机制
`yudao-server/pom.xml` 默认只 `dependency` 了 **system + infra**，其余 15 个模块在根 `pom.xml` 中被**注释掉**（编译提速）。按需取消注释即加入打包。

### 2.4 依赖主轴
- `yudao-server` → 聚合 `system` + `infra`（及其它按需激活模块）
- `system` → `infra`（system 依赖 infra）
- 其它业务模块一般依赖 `system`（调用用户/部门/权限 API）与 `infra`
- **唯一 Maven 级 API 拆分**：`yudao-module-trade-api`，用于解开 mall 内 `promotion ↔ trade` 的循环依赖

## 3. 分层与包结构（以 yudao-module-system 为例）

```
cn.iocoder.yudao.module.system/
├── api/         # 跨模块接口：XxxApi(接口) + XxxApiImpl(@Service) + dto/
├── controller/  # @RestController（admin/ 子包，@PreAuthorize + @Validated）
├── convert/     # MapStruct 映射器（DO ↔ DTO ↔ VO）
├── dal/
│   ├── dataobject/  # DO（继承 BaseDO / TenantBaseDO）
│   └── mysql/       # Mapper（MyBatis-Plus）
├── service/     # 业务逻辑
├── framework/   # 模块内支撑（如 sms 客户端）
├── job/         # Quartz 定时任务
├── mq/          # 消息生产 / 消费
├── enums/  util/
```

## 4. 关键架构模式

### 4.1 跨模块调用：本地 `api` 包（非 RPC）
单体版**没有 Feign/RPC**。跨模块通过 `api` 包 + Spring 本地注入完成：
- 接口：`AdminUserApi`（在 `api/user/`）
- 实现：`AdminUserApiImpl`（`@Service` 本地 bean，把 DO 转 DTO 返回）
- 调用方：`@Resource private AdminUserApi adminUserApi;`
- 微服务版（yudao-cloud）才把 `XxxApi` 拆成独立 `-api` Maven 模块并用 Feign。

### 4.2 多租户（tenant）
组件 `yudao-spring-boot-starter-biz-tenant`，**字段隔离**（共享库 + `tenant_id` 列，非独立 schema）：
- `TenantBaseDO`：所有 DO 继承，带 `tenantId`
- `TenantDatabaseInterceptor`：MyBatis 拦截器自动追加租户过滤
- `TenantContextHolder`：ThreadLocal 维护当前租户
- 覆盖 job / mq / redis / security / web，保证任务、消息、缓存也按租户隔离

### 4.3 权限 / 安全
- 基于 Spring Security；自定义表达式 Bean 名 **`ss`**
- 控制器：`@PreAuthorize("@ss.hasPermission('system:social-user:query')")`
- 登录：OAuth2 Access Token + 社交登录（JustAuth / WxJava）

### 4.4 代码生成器（codegen）
位于 **yudao-module-infra** 内（非独立模块）：基于 `mybatis-plus-generator` 解析表结构 + Velocity 模板，可一处生成前后端代码（`resources/codegen/` 存模板）。

### 4.5 任务 / 事务 / 限流降级
- 调度：**Quartz**（非 xxl-job）
- 分布式事务：**无 Seata**；本地事务 + MQ 最终一致 + `lock4j` 分布式锁
- 限流/降级：**无 Sentinel**；`protection` starter 提供 `@RateLimiter`(Redis 令牌桶) / `@Idempotent`(幂等) / `@Lock4j`(分布式锁) / `@Signature`(签名防篡改)

## 5. 前端架构（yudao-ui/）

`yudao-ui/` 下各目录是 **git submodule**（独立前端仓库），本仓库仅占位：
- `yudao-ui-admin-vue3`：Vue3 + Element Plus（**主推**）
- `yudao-ui-admin-vue2`：Vue2 + Element UI
- `yudao-ui-admin-vben`：Vue3 + Vben（Ant Design Vue）
- `yudao-ui-admin-uniapp`：管理端移动版
- `yudao-ui-mall-uniapp`：商城/会员移动版

**联调**：后端 `yudao-server` 跑 48080，API 前缀 `/prod-api`；nginx（admin 8080:80）反向代理 `/prod-api → server:48080`；开发环境由 Vite/Vue-CLI proxy 转发。

## 6. 部署与运维

- `script/docker/docker-compose.yml`：一键编排 `mysql:8 + redis:6-alpine + server(48080) + admin(nginx 8080)`
- `yudao-server/Dockerfile`：`FROM eclipse-temurin:8-jre`，`EXPOSE 48080`
- `script/jenkins/Jenkinsfile` + `script/shell/deploy.sh`：CI / 部署
- `sql/`：按方言分目录，默认 `sql/mysql/ruoyi-vue-pro.sql`（docker-compose 自动初始化）
- 本仓库 `script/` **无 k8s 目录**（仅 docker / jenkins / shell / idea / livekit-poc）

## 7. 架构图索引（见对话内联三张图）
1. **系统总体架构 · 部署拓扑**：客户端 → Nginx(8080) → yudao-server(48080) → 中间件（MySQL/Redis/Quartz/MQ/Flowable/JimuReport/S3/SkyWalking）
2. **Maven 模块架构 · 依赖与聚合**：基座(dependencies/framework) → 聚合层(server) → 业务模块(system+infra 默认激活，其余按需)
3. **模块内部分层 · 关键模式**：controller→service→convert→dal 分层 + 跨模块 api 包本地调用 + 横切能力（多租户/权限/数据权限/限流锁签名/代码生成器）

## 8. 快速上手建议
1. 仅跑 system+infra 即可启动最小可用后端（默认已激活）
2. 需要商城/支付/工作流等，取消根 `pom.xml` 对应模块注释后重新编译
3. 换 JDK17/21 请切 `master-jdk17` 分支（Spring Boot 3.5）
4. 初始化：`docker-compose up -d` 或手动导入 `sql/mysql/ruoyi-vue-pro.sql`
