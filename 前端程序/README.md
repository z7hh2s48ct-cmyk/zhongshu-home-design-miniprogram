# 众墅之家设计小程序 V1.2

这是独立的微信原生小程序前端工程，不依赖甲地灵光项目代码。

## 激活门禁（2026-09-05 调整）

小程序冷启动默认进入首页；但分享卡片、扫码/小程序码、订阅消息等**带明确直达意图**的场景会保留目标页，不再被弹回首页——否则分享与扫码链路整体失效。判定集中在 `miniprogram/app.js` 的 `DEEP_LINK_SCENES`（微信场景值 1007/1008/1036/1044/1011/1012/1013/1025/1047/1048/1049/1014/1043/1035/1074/1053）；未登记场景（含微信新增的未知场景）一律维持“回首页”，避免误放行。首页展示品牌、功能介绍和精选户型，不自动要求激活。“我的”基础页面、授权状态和联系客服也可查看。点击户型库、案例详情、AI设计、预算、消息、充值或个人业务入口时，未激活用户看到“激活后使用此功能”，可选“继续浏览”或“去激活”。

授权页是可返回的二级页，取消后留在原页面。激活成功返回刚才选择的功能，只导航，不自动生成、扣点、支付或投稿。未激活用户从任何入口（含分享/扫码直达）打开业务子页都会被拦回首页；授权失效后不继续显示和执行业务内容。**“先看过首页”只是引导前置，可被明确直达意图豁免；“已激活”是资金前置，不可豁免**——两条规则分别落在 `app.js` 与 `utils/access.js` 的 `checkPage`。

入口判定只在本次启动的首次 `onShow` 生效，避免从后台回前台时被二次拦截把用户从当前页拉走。

当前工程是交互原型：授权页沿用非空输入的本地演示验证，`v12Authorized` 不是可信使用权，也未接入微信身份绑定或后端授权接口。余额、生成结果与支付结果仍是演示数据。正式接入必须由服务端验证授权码、绑定账号并逐个校验业务接口；公开首页只能返回获准公开的展示字段。

“我的方案/户型投稿/收藏户型/充值记录/设置”目前仍为原有占位入口，激活后返回“我的”，不能据此认定这些功能已经实现。

运行 `npm test` 检查启动入口、功能弹窗、取消/成功回跳、直接打开子页、失效与存储失败，以及原生页面结构。门禁共用 `miniprogram/utils/access.js`，业务页通过 `protectedPage` 同时检查加载、显示与操作。`tests/activation-gate.test.js` 额外覆盖分享/扫码场景的直达放行、未激活经分享直达仍被拦截、未登记场景维持回首页，以及入口判定只生效一次。

## 目录

- `miniprogram/app.json`：24条原生页面路由，含T10预算七页、项目历史及旧区间兼容入口
- `miniprogram/pages`：首页、户型库、AI 设计、预算、账户及结果页面
- `miniprogram/components/v12-navbar`：适配微信胶囊位置的品牌导航栏；消息入口不占用页面右上角
- `miniprogram/custom-tab-bar`：首页、户型库、AI 设计、我的四个一级入口；“我的”按真实未读数显示角标
- `miniprogram/pages/profile`：承载消息中心入口；未读数量与消息页、底部角标共享
- `miniprogram/assets/v12`：从 V1.2 效果图拆分并校准的品牌、户型及方案素材
- `miniprogram/styles`：V1.2 颜色、字号、间距与安全区规范
- `miniprogram/components/tdesign-miniprogram`：本地化的 TDesign 图标组件与运行时，不依赖远程字体
- `tests`：路由闭包、页面结构、文案、图标与素材引用回归测试

## 运行

预算专项当前源码已接真实参数/目录/分项生成/保存/历史API，不再以globalData作为结果唯一存储；上文旧原型说明不能作为T10预算状态依据。实际联调需要完成207～209迁移的兼容后端、有效业务会话以及管理员核定配置的地区与选项。迁移不会自动发布生产单价；缺项显示待补预算，正式报价及项目临时补项仍待后续任务。开发/测试与微信视觉验收边界见[本批记录](../项目文档/T10-生成保存与配置结果实现验收-2026-09-08.md)。

使用微信开发者工具直接导入本目录，项目根目录保持为 `miniprogram/`。当前使用游客 AppID 方便独立预览；接入真实授权、支付及后端接口前，将 `project.config.json` 中的 `touristappid` 替换为众墅之家小程序 AppID。

样式源文件是 `.scss`，必须启用 `setting.useCompilerPlugins` 中的 `sass`。推荐导入外层 `前端程序/`，由其中的 `miniprogramRoot` 指向源码；如果本机已把内层 `miniprogram/` 单独导入，则它自己的 `project.config.json` 也必须启用相同编译插件，外层配置不会自动继承。否则页面、顶部导航和底部导航会整体丢失样式。修改后重新编译；若工具没有重新读取配置，关闭并重新打开项目（保留现有 AppID，无需构建 npm、重装依赖或改安全设置）。`npm test` 会检查两个实际存在的导入配置及本机覆盖，防止 Sass 开关再次被关闭。

图标字体和 TDesign 图标组件所需的 `tslib` 已随工程本地化，无需联网加载字体，也无需在开发者工具中单独执行“构建 npm”。

顶部状态栏、右上角微信胶囊和底部系统安全区由设备与微信运行时控制；页面自身通过胶囊测量、`rpx` 和 `env(safe-area-inset-bottom)` 适配不同设备。
