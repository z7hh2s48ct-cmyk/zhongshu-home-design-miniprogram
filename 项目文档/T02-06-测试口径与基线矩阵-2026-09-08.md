## 报告规则

- 完成度报告只引用同一提交的 GitHub Actions run 与可下载制品。
- “文件数”“声明方法数”“运行器测试数”“断言/检查点数”分栏，不再相加。
- 跳过、失败、取消和未运行分别记录；没有报告即 `NOT RUN`，不能写“全绿”。
- Stub E2E 通过的证据等级低于真实微信、支付、COS、内容审核和 AI Provider 验收。
