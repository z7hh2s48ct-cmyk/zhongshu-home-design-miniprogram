## 2. 关键业务结果

1. 报价草稿只能绑定 COMPLETE 且为当前的预算修订；系统测算总额复制后保持不可变。
2. 最终价与差额严格二选一，服务端反算另一个值，金额全部为整数分并执行边界检查。
3. 状态为 `DRAFT → PUBLISHED → WITHDRAWN`；建草稿与发布使用分离权限，发布/撤回均要求原因、预期版本和幂等键。
4. 预算产生新修订后旧草稿标记陈旧且禁止发布；调整已发布报价必须创建新版本。
5. 每个预算由最新已完成报价决定公开现态；撤回不会让历史已发布版本重新成为当前价。
6. App公开投影在服务端生成，不包含数量、单价、调整/撤回原因、内部备注或计价引用。
7. 金样通过：485,620.00元系统总额 +（-5,620.00元）差额 = 480,000.00元最终报价，系统总额未被覆盖。

## 3. 接口与权限

后台全局前缀为 `/admin-api`，下表列控制器路径：

| 接口 | 权限 |
|---|---|
| GET `/design/v1/budget/estimates/{budgetId}/quotes` | `design:budget:query` |
| GET `/design/v1/budget/quotes/{quoteId}` | `design:budget:query` |
| POST `/design/v1/budget/estimates/{budgetId}/quotes` | `design:budget:quote` |
| POST `/design/v1/budget/quotes/{quoteId}/publish` | `design:budget:quote-publish` |
| POST `/design/v1/budget/quotes/{quoteId}/withdraw` | `design:budget:quote-publish` |
| GET `/design/v1/design-projects/{projectId}/budget-quotes` | 已激活项目所属用户 |

权限常量已增加但没有自动给任何角色授权，避免越权扩大。
