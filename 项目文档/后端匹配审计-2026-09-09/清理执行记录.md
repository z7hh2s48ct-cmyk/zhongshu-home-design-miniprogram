## 3. 合同变化

### 会话与错误

| 语义 | 机器码 / 行为 |
|---|---|
| 会话无效、过期或刷新凭证无效 | `401`；兼容 HTTP 401 与 `CommonResult.code=401` |
| 已登录但未激活、授权撤销 | `1070001001`；保留受限会话，转激活入口 |
| 资源权限不足 | `403` 或现有领域拒绝码；不清令牌、不强迫重新激活 |
| 请求期间退出或切换账号 | 客户端 `SESSION_CHANGED`；旧响应不回填，新身份不重放旧操作 |

- access 有效期仍为 2 小时；refresh 独立为 30 天，落在 `user_session.refresh_expires_at`。
- `V20260909.102__independent_refresh_expiry.sql` 为现有记录按创建时间回填；旧吊销状态原样保留。新列有默认值，兼容旧服务写入。
- refresh 的读取、行锁、吊销、重签在同一事务；八路并发仅一次成功。重签时重新查询当前授权，响应返回真实 `restricted`。
- 小程序请求共用一次刷新，每个原请求最多重放一次，保留幂等键；网络刷新失败保留刷新凭证以便重试。
- 个人资料、记录、订单、结果等页面识别同身份令牌轮换，避免把正常刷新误判成换号。

### 展示读模型

- 用户详情从 `design_point_account` 读取可用余额，没有账户/流水时返回 0 和空列表；不再读取可能不存在的最后一条流水。
- “已发布”统计按关联 `design_case.publication_status=PUBLISHED` 且未删除计数，排除审核通过但未发布、下架和已删除案例。
- 投稿详情从实际案例读取发布状态，停止按“有 publishedCaseId”直接返回 PUBLISHED。
- 项目/结果/候选 ID 保持字符串；已有订单金额、到账状态、CLOSED 停止轮询逻辑保留。

### 生成报价与继续设计

- 新增 `GET /app-api/design/v1/generation-price-quotes?stage=FLAT|ELEVATION&count=N`，返回单价、总点数、字符串 ruleId、ruleVersion、报价展示有效期。
- 初次生成、重新生成、恢复草稿生成均先取当前报价并明确确认；移除固定的 5/6/10/12 点展示。
- 创建平面/立面任务随请求提交 `priceConfirmation`。实际扣点事务比较规则 ID 与版本；变化时拒绝扣点并要求重新确认。已成功请求的幂等重试复用原任务，不再扣点。
- 兼容边界：旧客户端可缺省确认字段并按当前规则计价；本次小程序已接入确认。正式封禁旧合同须先确认发布客户端版本。
- 项目详情不传 jobId 时也返回当前用户、当前项目、当前阶段的最新任务和恢复动作；任务详情补回 projectId。
- “我的 → 方案记录 → 继续设计”可回到生成中、平面/立面候选、立面设置或恢复草稿/失败后的平面生成。旧结果版本仍按明确版本 ID 回看。
- 恢复时回填选中平面的资产；跨账号/跨项目不能查询其他任务。恢复后的立面重新生成若缺本地配置，会重新进入设置页。

### 消息与未开放入口

- 后端以 ID 降序游标、`limit + 1` 探测下一页；非法游标明确拒绝。前端保留 nextCursor、bizType/bizId，支持加载更多、失败重试和去重。
- 消息关联投稿、项目、充值订单可打开对应记录；AI 任务通知先按本人权限读取任务，再打开项目记录。已读消息仍可跳转；未知关联类型不拼接任意 URL。
- 已读回执先验证消息归属，不能给他人或不存在的消息写回执。
- 移除尚未接通的“上传参考图片”卡片与无效分支；保留真实草图上传和户型库案例参考。
