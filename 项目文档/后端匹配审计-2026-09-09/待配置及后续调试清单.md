| 服务 | 需要准备的配置 / 资料 | 代码接线与随后验收 |

| 微信支付 | 商户号、小程序绑定关系、API v3 密钥、商户私钥/证书或平台公钥信息、证书序列号、支付/退款回调 HTTPS 地址 | 当前 PaymentPort / 订单 / 账本保留；仍须实现真实适配器、payParams 返回与有效期、通知 HTTP 入口、验签解密和预支付幂等。之后验证拉起支付、取消、超时、回调到账、重复通知和退款 |
| 私有对象存储（先选定 COS / OSS 等） | 服务商、区域、Bucket、访问端点、最小权限凭据或 STS 配置、签名有效期、上传/下载合法域名 | 当前 LocalObjectStorageAdapter 仅用于 zsdev；需实现真实对象存储并明确上传方法/请求头，二进制 PUT 与 multipart POST 分别处理；测试真机上传、大小/Hash/权限校验、过期签名、生成结果可达 |
| 内容审核 | 选定审核服务、账号及 API 凭据位置、审核场景与回调（如有） | 真实审核适配器替换直通 Stub；验证允许、拒绝、超时和人工处理状态，不能把网络失败当通过 |
| AI Provider / Runtime | Provider 名称、API Key 配置位置、模型及版本、配额、Runtime 部署地址、输出规范、隔离区存储访问权限 | 当前任务/租约/签名入口/结算已保留并通过本地生成夹具；真实 Runtime 须领取任务、调用 Provider、回写隔离区与结果，验证失败退款、取消竞争、租约失效及最终素材 |

除 `ZS_WX_APPID` 等下节列明的现有项外，上述供应商凭据配置名需随真实适配器落地确定。不要在 `.env` 随意新增同名变量后就认定代码已经消费它。

## 2. 已有正式环境配置项

| 当前已接线项 | 用途 |
|---|---|
| `ZS_PG_URL` / `ZS_PG_USERNAME` / `ZS_PG_PASSWORD` | 正式 PostgreSQL 数据源与 Flyway |
| `ZS_REDIS_HOST` / `ZS_REDIS_PORT` | Redis 地址；正式 Redis 鉴权/TLS 按部署配置接线核对 |
| `ZS_WX_APPID` | 身份域的小程序 AppID；不代表真实身份适配器已实现 |
| `ZS_ACCESS_CODE_PEPPER` / `ZS_ACCESS_CODE_PEPPER_VERSION` | 激活码 HMAC 与版本；换值前必须制定现有码兼容/轮换方案 |
| `ZS_ACCESS_CODE_ARTIFACT_KEY` | 一次性激活码交付制品的加密密钥；采用服务要求的 Base64 编码密钥格式 |
| `ZS_INTERNAL_SECRET` / `ZS_INTERNAL_REPLAY_WINDOW` | AI Runtime 内部请求签名与防重放；Runtime 和后端保持一致 |
| `ZS_DRIVER_ENABLED` / `ZS_EXPORT_WORKER_ENABLED` | 结算补偿驱动和导出执行器开关；只有真实依赖就绪后按部署职责启用 |
| `ZS_SEED_DEV_DATA` / `ZS_DEV_CONTENT_ENDPOINT` | 开发数据播种与本地内容端点；正式部署应关闭 |

正式部署不要启用 zsdev。开发 Stub 与本地存储已被 Profile 排除，真实实现尚未注册时应用会缺少必需端口而无法正常启动；这是明确的接入门槛，不是填完密钥即可绕过的问题。现有 pg 配置中的数据库开发默认值也须按实际环境覆盖。

## 4. 配置后的调试顺序

1. 先部署测试数据库、Redis、私有存储与真实身份适配器，验证账号稳定和真实上传/下载。
2. 接入内容审核和 AI Runtime，验证计价确认、生成、取消/失败退款、退出恢复、结果资产访问。
3. 接入真实支付和回调，验证预支付参数、付款、到账、重复/乱序通知、主动查单和退款。
4. 补正式协议页面与数据请求执行流程，再验证版本变更、导出成功/失败与注销后的会话/数据行为。
5. 完成真机验证和上线观察后，根据访问及数据证据实施 C06；深度数据库清理另作可回退迁移。
