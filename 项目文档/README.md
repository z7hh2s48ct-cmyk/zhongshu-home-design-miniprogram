1. 只在实时状态看板更新当前状态；历史报告不再追加“最新附录”。
2. 任务完成后，状态看板必须链接可达提交和可重复验证命令。
3. 新文档应从本入口登记；过期文档保留但必须标明历史状态。
4. 本地链接必须可解析；外部制品必须有稳定 URL、责任人和保留周期。
