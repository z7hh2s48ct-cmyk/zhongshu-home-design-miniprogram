# 正式环境部署指南

日期：2026-10-03
适用：将后端 + 管理后台 + 小程序前端从本地开发环境发布到正式服务器
前提：已有一台 Linux 服务器（建议 4C8G 以上）+ 域名 + HTTPS 证书

---

## 一、总体架构

```
用户微信 → 小程序（发布到微信平台）→ HTTPS → Nginx → Spring Boot(48080)
                                          ↘ /static/ → 管理后台静态文件
                                          ↘ /admin-api/ → Spring Boot
PostgreSQL(5432) ← Spring Boot
Redis(6379) ← Spring Boot
COS 私有桶 ← 图片/文件存储
AI Runtime(8081) ← 后端内网调用
```

---

## 二、后端部署

### 2.1 服务器环境准备

```bash
# Java 17
sudo apt install openjdk-17-jdk -y
java -version

# PostgreSQL 16
sudo apt install postgresql-16 -y
sudo -u postgres psql -c "CREATE USER zhongshu WITH PASSWORD '强密码';"
sudo -u postgres psql -c "CREATE DATABASE zhongshu_design OWNER zhongshu;"

# 导入底座表（system/infra 表结构）
psql -U zhongshu -d zhongshu_design -f sql/postgresql/ruoyi-vue-pro.sql

# Redis
sudo apt install redis-server -y
sudo redis-cli CONFIG SET requirepass "强密码"
```

### 2.2 打包

```bash
# 本地执行
cd 后端程序
./mvnw -pl yudao-server -am package -DskipTests
# 产物：yudao-server/target/yudao-server.jar
```

### 2.3 服务器环境变量

创建 `/opt/zhongshu/.env`（权限 600，不入库）：

```bash
# 数据库
ZS_PG_URL=jdbc:postgresql://127.0.0.1:5432/zhongshu_design
ZS_PG_USERNAME=zhongshu
ZS_PG_PASSWORD=强密码
ZS_REDIS_HOST=127.0.0.1
ZS_REDIS_PORT=6379
ZS_REDIS_PASSWORD=强密码

# 微信小程序身份（正式）
ZS_WX_APPID=wx5753299f05a5c138
ZS_WX_APPSECRET=从小程序管理后台获取（见第四节）

# 授权码安全（正式强密钥，Base64 的 32 字节）
ZS_ACCESS_CODE_PEPPER=生产环境强随机字符串
ZS_ACCESS_CODE_PEPPER_VERSION=v1
ZS_ACCESS_CODE_ARTIFACT_KEY=Base64编码的32字节密钥

# COS 对象存储
ZS_COS_ENDPOINT=https://cos.区域.myqcloud.com
ZS_COS_REGION=ap-xxx
ZS_COS_BUCKET=你的桶名
ZS_COS_SECRET_ID=子账号SecretId
ZS_COS_SECRET_KEY=子账号SecretKey

# AI 供应商
ZS_AI_BASE_URL=https://api.apilio.ai/v1
ZS_AI_API_KEY=真实Key
ZS_AI_MODEL=gpt-5.6-sol

# 微信支付（商户号）
ZS_PAY_MERCHANT_ID=商户号
ZS_PAY_MERCHANT_SERIAL_NO=证书序列号
ZS_PAY_API_V3_KEY=APIv3密钥
ZS_PAY_MERCHANT_PRIVATE_KEY_PATH=/opt/zhongshu/keys/apiclient_key.pem
ZS_PAY_NOTIFY_URL=https://你的域名/design/v1/payments/wechat/notify
ZS_PAY_REFUND_NOTIFY_URL=https://你的域名/design/v1/payments/wechat/refund-notify

# 内容审核（腾讯云）
ZS_MODERATION_SECRET_ID=审核子账号ID
ZS_MODERATION_SECRET_KEY=审核子账号Key
ZS_MODERATION_BIZ_TYPE=your_biz_type

# Runtime 内部签名
ZS_INTERNAL_SECRET=生产环境强随机32字节

# 导出 Worker
ZS_EXPORT_WORKER_ENABLED=true
```

### 2.4 systemd 服务

创建 `/etc/systemd/system/zhongshu.service`：

```ini
[Unit]
Description=Zhongshu Design Backend
After=network.target postgresql.service redis-server.service

[Service]
Type=simple
User=zhongshu
WorkingDirectory=/opt/zhongshu
EnvironmentFile=/opt/zhongshu/.env
ExecStart=/usr/bin/java -Xmx2g -jar yudao-server.jar --spring.profiles.active=pg,prod
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable zhongshu
sudo systemctl start zhongshu
# 验证
curl http://127.0.0.1:48080/actuator/health
# 期望返回 {"status":"UP"}
```

> **注意**：`prod` Profile 不含 `local`/`zsdev`，Stub 身份/支付/审核全部禁用。Flyway 会自动执行全部迁移（包括最新的权限种子和报价状态机）。

### 2.5 AI Runtime 部署

```bash
# 在同一台或内网另一台服务器
cd ai-runtime
ZS_AI_CORE_URL=http://127.0.0.1:48080 \
ZS_INTERNAL_SECRET=同上 \
ZS_AI_STORAGE_MODE=cos \
ZS_AI_STORAGE_ROOT=/data/ai-assets \
ZS_AI_IMAGE_MODEL=gpt-image-2 \
ZS_AI_IMAGE_QUALITY=high \
ZS_AI_REQUEST_TIMEOUT_MS=300000 \
node src/runtime.mjs &
```

建议也配 systemd 或 pm2 守护。

## 三、管理后台部署

### 3.1 打包

```bash
cd 管理后台
corepack pnpm install --frozen-lockfile
corepack pnpm build:prod
# 产物：dist/ 目录
```

### 3.2 Nginx 配置

```nginx
server {
    listen 443 ssl;
    server_name 你的域名;

    ssl_certificate /etc/ssl/certs/你的证书.pem;
    ssl_certificate_key /etc/ssl/private/你的私钥.key;

    # 管理后台（SPA）
    location / {
        root /opt/zhongshu/admin-dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API（小程序 + 管理后台共用）
    location /app-api/ {
        proxy_pass http://127.0.0.1:48080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 20m;
    }

    location /admin-api/ {
        proxy_pass http://127.0.0.1:48080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 微信支付回调
    location /design/v1/payments/ {
        proxy_pass http://127.0.0.1:48080;
    }
}

server {
    listen 80;
    server_name 你的域名;
    return 301 https://$server_name$request_uri;
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 四、小程序发布

### 4.1 在微信管理后台配置合法域名

你当前打开的小程序管理后台 → **开发管理 → 开发设置 → 服务器域名**，添加：

| 域名类型 | 填写内容 |
|---|---|
| request 合法域名 | `https://你的域名` |
| uploadFile 合法域名 | `https://你的域名` |
| downloadFile 合法域名 | `https://你的域名` 及 `https://你的COS桶域名` |

### 4.2 获取 AppSecret

同页面 → **开发设置 → AppSecret** → 生成并复制 → 填入服务器 `.env` 的 `ZS_WX_APPSECRET`

### 4.3 构建发布包

```bash
cd 前端程序

# 一键构建（替换为你的正式域名和 AppID）
npm run build:release -- \
  --api-base https://你的域名 \
  --asset-base https://你的COS桶域名 \
  --appid wx5753299f05a5c138 \
  --out release-v1.0.0

# 产物在 release/release-v1.0.0/ 目录（自动通过 check-release 门禁）
```

### 4.4 通过微信开发者工具上传

> **这是小程序发布到微信平台的唯一方式**——不是在网页管理后台上传代码，而是用桌面端的微信开发者工具。

1. **打开微信开发者工具**（本机已安装）
2. **导入项目**：
   - 项目目录：选择 `release/release-v1.0.0/`
   - AppID：`wx5753299f05a5c138`（会自动读取）
3. **预览确认**：点击"预览"扫码，确认功能正常
4. **上传**：点击右上角"上传"按钮 → 填版本号 `1.0.0` + 备注 → 确认上传
5. 上传成功后代码出现在管理后台的 **版本管理 → 开发版本**

### 4.5 提交审核与发布

回到浏览器中的小程序管理后台：

1. **版本管理 → 开发版本** → 找到刚上传的版本
2. 点击 **提交审核**
3. 填写审核信息（功能页面截图、服务类目等）
4. 等待微信审核（通常 1~7 天）
5. 审核通过后 → **版本管理 → 审核版本** → 点击 **发布**
6. 用户即可搜索/扫码使用

### 4.6 体验版（审核前测试）

审核通过前，在管理后台 **版本管理 → 开发版本** → 选为 **体验版**，添加体验成员的微信号，体验成员扫码即可在真机使用。

## 六、回滚方案

```bash
# 后端回滚：替换旧 jar 后重启
sudo systemctl stop zhongshu
cp yudao-server.jar.bak yudao-server.jar
sudo systemctl start zhongshu

# 小程序回滚：管理后台 → 版本管理 → 已发布版本 → 回退
# 管理后台回滚：替换旧 dist 目录
```

## 七、常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 小程序真机请求失败 | 合法域名未配 | 4.1 节补配 |
| 登录返回 401 | `ZS_WX_APPSECRET` 错误 | 核对管理后台 AppSecret |
| 支付拉起失败 | 商户号/证书/回调地址错误 | 核对 `.env` 支付五项 + 商户平台后台 |
| 图片上传失败 | COS 子账号权限或桶 CORS | 检查 COS 控制台权限和 CORS |
| AI 任务超时 | Runtime 未启动或密钥错 | 检查 Runtime 进程和 `ZS_AI_API_KEY` |
| Flyway 报错 | 库有旧残留 | 新库重跑或 `repair` |
