# 设计 Token 与图标一致性排查报告（2026-09-29）

> 范围：`前端程序/miniprogram` 全部自有样式（30 个页面 scss、3 个公共组件、custom-tab-bar、styles/），不含 `components/tdesign-miniprogram` 组件库本体。
> 结论先行：**设计标准不存在"多套规范文档"，但事实上存在两套并存的色板 + 全面碎片化的取值**。自有样式共出现 **153 种不同色值**、**30 种字号**、**21 种圆角**、**7 种阴影**、**9 种主按钮规格**；图标层面**全项目没有 SVG**，实际是 TDesign 字体图标为主、混入衬线字符与 Unicode 符号。

---

## 一、基准层现状

### 1.1 Token 定义（styles/v12-tokens.scss，仅 8 个色值变量）

```scss
$v12-brand-brown: #6a3b1b;    // 品牌棕
$v12-primary-brown: #7b5532;  // 主操作棕
$v12-deep-coffee: #2f2925;    // 主文字
$v12-warm-gold: #c8a679;      // 点缀金
$v12-page-beige: #f7f4ee;     // 页面底
$v12-surface: #fffdf8;        // 卡片面
$v12-secondary-text: #786858; // 次文字
$v12-divider: #e8ded1;        // 分隔线
```

缺失：功能色（成功/警告/危险）、字阶、圆角、间距、控件高度、阴影、图标规格——**全部没有 token**，页面只能自造值。

### 1.2 全局公共类（styles/v12-theme.scss）

提供 `v12-page / v12-content / v12-card / v12-primary-button / v12-secondary-button / v12-disabled-button / v12-section-title / v12-muted / v12-fixed-action` 等类。

两个结构性问题：

1. **`app.scss` 没有引入 v12-theme.scss**（只含 @font-face 与 scroll-view 规则），主题类靠每个页面 scss 自行 `@import`，编译后整份主题被复制进每个页面的 wxss；页面再随意覆写同名类，覆写点分散且不可见。
2. `pages/profile/privacy.scss`、`components/v12-desktop-guide/index.scss` **完全没有引入 token/主题**，全部裸写色值。

- 导航标题色 `#171717`（v12-navbar）与全局主文字 `#2f2925` 不一致。

### 2.8 图标：无 SVG，是三套体系混用（回应"SVG 改造"诉求）

先澄清事实：**全项目 wxml/scss/assets 中没有任何一处 SVG**（无 `<svg>` 标签、无 .svg 资源、无 data:image/svg）。小程序 wxml 本身也不支持内联 `<svg>` 元素；SVG 只能以 `<image src>` 或 CSS background 呈现。"小程序自定义图标"并非标准概念，标准做法就是：**字体图标（iconfont / 组件库图标组件）或图片资源**。

实际现状（用户看到的"SVG 图标"即 TDesign 字形）：

1. **TDesign `t-icon` 字体图标（主力，正确路线）**：约 20 个页面、35 种图标名。但 **17 种尺寸**（14~64px，含 15/17/23/25/27/29 等非阶梯值），且颜色在 wxml 里内联写死（#7b3f17/#707070/#9a6d39）。
2. **custom-tab-bar 混入第二体系**：`.tabbar-glyph` 用 Georgia 衬线字体渲染字符当图标（46rpx），同一栏内其余 tab 用 t-icon——同一组件两套图标语言。
3. **Unicode 符号图标**：`✓` 硬编码在 ai-design/generating、ai-design/elevation-setup、wallet/recharge 三个页面的 wxml 里。

结论：**不需要"改成自定义图标"，应继续用 TDesign 图标并做收敛**（理由见方案三）。

## 三、解决方案

### 方案一：扩充 Token 层（唯一数据源）

`styles/v12-tokens.scss` 从 8 个色值扩为完整体系（建议值，色值尽量沿用现有最高频值以减小视觉跳变）：

```scss
// —— 色彩：语义化 ——
$v12-brand:   #6a3b1b;  $v12-primary: #7b5532;  $v12-primary-deep: #8b4818; // 渐变起点
$v12-gold:    #c8a679;  $v12-gold-deep: #b9690b;
$v12-text-1:  #2f2925;  $v12-text-2: #786858;   $v12-text-3: #a89a8c;
$v12-danger:  #b93b2e;  $v12-danger-bg:  #fcebea;
$v12-success: #36863b;  $v12-success-bg: #f2f8f1;
$v12-warning: #b9690b;  $v12-warning-bg: #fdf5e9;
$v12-page:    #f7f4ee;  $v12-surface: #fffdf8;  $v12-surface-alt: #f4f0e9;
$v12-divider: #e8ded1;
// —— 圆角（收敛 21 → 5）——
$v12-radius-sm: 12rpx;  $v12-radius-md: 16rpx;  $v12-radius-lg: 24rpx;  $v12-radius-xs: 8rpx;  $v12-radius-full: 999rpx;
// —— 字阶（收敛 30 → 9）——
$v12-font-xs: 20rpx; $v12-font-sm: 22rpx; $v12-font-body: 24rpx; $v12-font-md: 26rpx; $v12-font-lg: 28rpx; $v12-font-xl: 32rpx; $v12-font-title: 34rpx; $v12-font-hero: 40rpx; // + 特例 46rpx 首页 hero
// —— 控件高度 ——
$v12-control-sm: 68rpx; $v12-control-md: 80rpx; $v12-control-lg: 92rpx;
// —— 阴影（收敛 7 → 2）——
$v12-shadow-card: 0 10rpx 30rpx rgba(72, 49, 32, 0.07);
$v12-shadow-primary: 0 10rpx 24rpx rgba(106, 59, 27, 0.14);
```

### 方案二：收敛公共类，禁止页面覆写

1. `v12-theme.scss` 为按钮增加**尺寸变体**：`.v12-primary-button--sm(68) / --md(80)`、默认 92；禁用态唯一化（$v12-disabled）。页面覆写（ai-design/index、library/detail、elevation-setup、wallet/recharge、generating、record）全部改为变体类。
2. 删除自造按钮类：`.btn-next`、`.next-button`、`.budget-primary`、`.dt-btn-primary` → 统一 `v12-primary-button`；渐变唯一 `#8b4818→$v12-primary`；`min-height: 48px` 改回 rpx 体系。
3. budget 系换肤：`.budget-page` 底色/字色/分隔线改为 token；`pages/budget/shared.scss` 里的色板 B 全量按映射表替换，budget 与其他模块页面底色统一 `#f7f4ee`。
4. `privacy.scss`、`v12-desktop-guide` 引入 tokens；`app.scss` 顶部改为全局 `@import v12-theme.scss`，删除各页重复引入（注意先验证 DevTools sass 插件下 app 级样式对页面的作用，保留页面级兜底亦可，但必须停止覆写）。
5. 页面水平边距统一 32rpx、卡片内边距统一 32rpx、卡间距 24rpx。

### 方案三：图标统一到 TDesign（回答"是否用 TDesign 图标"）

**是——继续用 TDesign 图标，不要引入第二套。** 理由：

- tdesign-miniprogram 已内置（含 icon 字体，app.scss 已嵌入字库），现用 35 个图标名全部是标准 TDesign 名录，无缺字风险；
- 引入 iconfont.cn 自建库或另一个图标库 = 引入第二种字形/线宽语言，与"高级感"目标相反；
- 高级感来自**克制与一致**：一套图标语言、少数几种尺寸、颜色随 token。

落地动作：
1. 图标尺寸收敛为 4 档：16 / 20 / 24 / 32px（现 17 种全量归并；25px 的 tab 栏图标→24px）；
2. wxml 内联 `color` 改为从 token 派生的固定几档（主棕/次灰/危险红），tab-bar 的 `#7b3f17/#707070`、v12-state 的 `#9a6d39` 入表；
3. `custom-tab-bar` 的 Georgia 衬线 glyph 改为 t-icon（或品牌 PNG logo），消灭"同栏两套图标"；
4. 三个页面的 Unicode `✓` 改为 `t-icon name="check-circle-filled"`；
5. 描边/填充风格统一：正文场景用 filled 系列时保持同页一致（如 chevron/check 统一风格）。

### 方案四：防回归（关键，否则修完又散）

新增 `scripts/check-design-tokens.js`（Node 脚本，接入 git pre-commit / CI）：

- 规则 1：`pages/**`、`components/**`、`custom-tab-bar/**` 的 scss/wxml 中禁止裸 hex（白名单：v12-tokens.scss、映射过渡期清单）；
- 规则 2：font-size / border-radius / t-icon size 必须命中阶梯值（过渡期输出 warning，之后 fail）；
- 规则 3：新增 `*-button/btn/primary` 类名需 lint 放行（只允许用 v12 变体）。

### 实施顺序建议

| 阶段 | 内容 | 风险 |
|---|---|---|
| P1（半天） | tokens 扩充 + 映射表脚本化批量替换色值 | 低，纯等值/近值替换，逐页 diff 自测 |
| P2（半天） | 按钮类收敛 + 页面边距/底色统一 | 中，需过一遍各页真机/模拟器 |
| P3（2 小时） | 图标尺寸/颜色收敛、tab-bar glyph、✓ 替换 | 低 |
| P4（1 小时） | lint 脚本 + pre-commit | 低 |

> 视觉回归手段：本地无自动化截图基线，建议 P1/P2 每批替换后在 DevTools 逐页目检关键页（home、ai-design/index、budget/input、budget/result、profile/index、wallet/recharge）。

## 附录：组件间距排查与整改（同日第二轮）

**问题数据**：gap 值 17 种（4~38rpx 无节奏，高频 14/18/22 均不在网格上）；padding/margin 大量奇数值（25/19/11/15/27rpx 等）与手工光学边距（如 `margin: 27rpx 3rpx 20rpx`）；v12-card 无默认内边距，各页卡片 20~32rpx 各自为政——"拥挤感"的结构性来源。

**整改**：
1. tokens 新增间距阶梯 `$v12-space-1~6`（8/16/24/32/40/48rpx），确立 **4rpx 倍数网格** 为间距规则；
2. `scripts/design-spacing-normalize.mjs` 归并 193 处（余 2 向上取，紧端只放宽不收紧）；首版脚本曾误伤同行 border 值（1rpx→0rpx），已回滚并改为属性段内替换后重跑，边框零损伤；
3. lint 新增 R6：padding/margin/gap 的 rpx 值必须 4 的倍数（calc/env 豁免）。

**户型库筛选重设计**：选中态由描边式（白底棕边）改为**填充式渐变胶囊**（与来源 Tab 同一激活语言）；筛选 chip 升级为胶囊形（radius-full + surface-alt 底），加大点击区（12×24rpx 内边距）并支持换行；区块间距上节奏（搜索 32 / Tab 24 / 筛选 24 / 元信息 28-20）；移除 sort-row 手工 3rpx 光学边距；卡片文案区内边距 18→20rpx。
