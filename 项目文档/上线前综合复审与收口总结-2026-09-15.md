## 2. 三端评审

### 2.1 后端（Spring Boot 3 / Java 17 模块化单体）

成熟度：高。identity / design / commerce / ai-orchestration / infra 五模块经接口端口协作，同一 PostgreSQL 数据源 + JDBC 参数化 SQL + Outbox/Inbox 可靠事件。32 个 Flyway 前向迁移 + 15 个回滚 SQL。

- R03 资产覆盖修复确认：上传键与净化键分离，验收后写唯一 `accepted/{assetId}/{validationToken}` 键并以 CAS 固化（`后端程序/yudao-module-design/src/main/java/cn/iocoder/yudao/module/design/asset/AssetService.java:214`）。
- R04/R05 支付修复确认：幂等建单与 ensurePrepay 拆分（租约 + fenced CAS）；`FOR UPDATE SKIP LOCKED` + `recovery_after` 轮转退避消除补偿饥饿，渠道终态持久化，CREATED 与已支付未履约纳入恢复（`后端程序/yudao-module-commerce/src/main/java/cn/iocoder/yudao/module/commerce/payment/RechargePaymentService.java:715-743`）。
- R01 审核修复确认：腾讯 IMS 适配器对 PDF/超 7MiB fail-safe 保守拒，Semaphore 限流 + 日配额落库；生产 profile 禁止 stub（`后端程序/yudao-module-design/src/main/java/cn/iocoder/yudao/module/design/asset/TencentImsModerationAdapter.java:25,65-66`）。
- R06 生产守卫确认：启动期强制校验 mock 关闭、Worker 显式开启、Actuator 白名单、必需机密存在，缺失即启动失败（`后端程序/yudao-server/src/main/java/cn/iocoder/yudao/server/wiring/RealServiceWiringPolicy.java:135-185`）。
- R02 AI Runtime：独立 Node 进程（`ai-runtime/`），Java 侧内部接口 HMAC-SHA256 签名 + ±300s 防重放，密钥为空全拒；**签名密钥分发、Runtime 生产部署、apilio 真实生图渠道均无验收证据**，付费生成主链仍是「协议通了、真实图片没跑过」。

遗留维护问题：`RechargePaymentService` 仍超 1000 行；导出为内存组装（有 1 万行/10MB 硬上限，风险受控）。

### 2.2 小程序（原生 JS/WXML + TDesign，30 页面）

完成度：高。30 页全部真实 API 驱动，mock/TODO/假数据零命中。网络层为亮点：token 刷新单飞 + 同代际并发重放 + 会话竞态防护；支付失败分支分类、禁止重复建单、幂等键贯穿。T14「我的当地单价」页已注册且走授权门禁。本轮实测 **225/225 测试通过**。

高效性短板：源码目录 7.5MB（assets 6.3MB，hero 图单张 1.87MB），30 页全在主包、无分包。`build:release` 机制已建（CDN 替换 + 1.8MB 主包门禁）但**从未实跑**（release-manifest 自认 `compiledPackageVerified:false`、`cdnUploaded:false`）。

### 2.3 管理后台（Vue3 + TS + Vite + Element Plus）

成熟度：高。众墅 19 条业务路由权限码与后端 `@PreAuthorize` 一一对应；R16 处置方案：旧 wangeditor 移除、换 `@wangeditor-next` 维护分叉 + 构建期供应链门禁（bundle 含旧包即构建失败）+ 四端 SBOM（Trivy 实扫后端 299 组件仅剩 1 条已缓解中危，高危/严重为 0）。

发现业务缺陷：充值套餐编辑页**编辑模式不回填原数据即保存**（`管理后台/src/views/zs/recharge/plan-edit.vue:66-75`），存在误覆盖线上套餐风险；且 `package.json` 无 `test` 脚本入口（11 个测试文件未接命令）。
