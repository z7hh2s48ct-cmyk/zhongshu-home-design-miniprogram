# 众墅之家设计小程序视觉设计规范

## 一、设计定位

视觉关键词：**新中式、可信赖、温润、专业、轻量 AI、乡墅生活方式**。

页面不是科技炫技型 AI 产品，也不是传统工程软件。第一眼应让客户感受到“这是懂乡墅、懂家庭建房、能快速给出方向的品牌工具”。

## 二、平台与画面

- 平台模式：跨平台高品质移动端，小程序交互优先。
- 效果图呈现：统一放在简洁的深咖色手机框中，手机不抢画面。
- 画幅：竖版单屏，一张效果图对应一个页面，不用多屏拼贴替代独立页面。
- 安全区：保留状态栏、标题区、底部手势区与导航区。

## 三、品牌色

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| Logo 主棕 | `#6A3B1B` | 品牌识别、标题、关键图标 |
| 深咖 | `#3F3025` | 正文、手机框、深色按钮 |
| 暖米白 | `#ECE4D9` | 页面主背景 |
| 瓷白 | `#FFFDF8` | 卡片和输入区 |
| 主金色 | `#A9855B` | 主操作与高亮 |
| 柔金色 | `#C8A679` | 次级按钮、线条、状态 |
| 灰褐 | `#8C7B6A` | 辅助文字 |

禁止使用大面积紫蓝 AI 渐变、霓虹光、随机高饱和色和无意义玻璃卡片。

## 四、字体与层级

- 大标题：宋体/思源宋体气质，强调建筑文化与品牌感。
- 正文与按钮：清晰的现代黑体，保证移动端可读性。
- 按 390px 宽的小程序屏幕设计，不使用宣传海报式超大字。
- 顶部导航标题：18–20px；页面主标题：26–30px；卡片标题：16–18px。
- 正文与表单标签：13–15px；主按钮：16–17px；辅助说明：12–13px。
- 页面主标题通常控制在屏幕宽度的 65% 以内，标题区域高度不超过首屏的 15%。
- 每屏只保留一个主标题和一个主操作。
- 不用过小标签，不把大量信息压缩进同一张卡片。

## 五、图片语言

- 建筑：新中式、新闽派、现代乡墅，真实自然光，能看清屋顶、门窗、材质和庭院关系。
- 平面图：浅米底、深咖线稿、少量柔金标注，避免彩色工程图的杂乱感。
- 背景：参考品牌资料中的象牙白丝绸流线，控制透明度，只作为空间层次。
- 质感：细腻哑光、轻微纸张颗粒和柔和阴影，不做廉价高光。

## 六、组件规则

- 圆角：主卡片 20–24px，输入框 14–16px，按钮使用柔和胶囊形但不过度。
- 主按钮：柔金底、深咖或白色文字；一屏只允许一个主要按钮。
- 筛选：优先使用横向轻筛选，不堆叠大量标签。
- 图片卡：大图优先，文字放在下方或使用柔和渐隐保护可读性。
- 图标：带一点屋檐、院落、尺规的品牌特征，保持统一线条粗细。

## 七、导航

底部导航统一为：**首页 / 模板库 / AI设计 / 我的**。

预算不是独立一级导航，主要从首页和方案结果进入，减少入口复杂度。

## 八、页面气质校验

每张图必须满足：

1. 像真实可开发的小程序，不像手机里的网页海报。
2. 中文标题和按钮符合真实小程序字号，清晰但不具海报感。
3. 保持 Logo 棕、暖米白、柔金三色关系。
4. 建筑图片承担主要视觉，不用无意义图表装饰。
5. 不承诺施工图、精确报价或可直接施工。
