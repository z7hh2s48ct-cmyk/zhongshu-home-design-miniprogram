# 众墅之家设计小程序页面效果图生成清单

## 一、效果图分类

1. **品牌与入口类**：建立品牌第一印象，明确三个核心能力入口。
2. **模板库类**：展示公司历史户型与审核通过的用户 AI 作品。
3. **AI 生成类**：覆盖模板参考生成、自由提示词生成、生成进度和结果操作。
4. **预算类**：主链路三页「信息填写 → 报价结果 → 价格分项明细」（12/13/14），对照公司 2026 预算公式；只展示结果与子项金额，计算方法不对外。旧版 09/10 及首版分项图移入 `effects/drafts/` 对照。
5. **个人资产类**：展示生成历史、投稿状态和已上架作品。

## 三、流程覆盖

```text
首页 → 模板库 → 模板详情 → 参考生成 → 生成中 → 生成结果 → 预算
  └→ AI直接生成 ────────────────┘          └→ 发布模板 → 我的方案
```

## 四、本轮不生成

- CAD、BIM、3D 建模和施工图编辑页面。
- 支付充值、会员体系、创作者分成页面。
- 点赞、评论、排行榜等社区页面。
- 管理后台页面。
