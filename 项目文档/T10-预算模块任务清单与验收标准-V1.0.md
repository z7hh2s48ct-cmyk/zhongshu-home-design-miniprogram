## 1. 工作包定位与开工条件

T10 是在原 T01～T09 总计划之外追加的预算专项，按用户最新优先级先推进；不重新编号旧任务，也不宣称 T02 的 Docker/远端 CI 待验收项已完成。

- 本清单编制时业务代码尚未开工；用户已于2026-09-08确认开发，当前实现与验证状态见看板及[第一批记录](T10-第一批实现与验收记录-2026-09-08.md)。
- 顺序原则：先数据合同和后端闭环，再后台配置、小程序联调，最后自动化与视觉验收；各任务实现时同步写对应测试，不将全部测试留到末尾。
- 本地缺少 Docker 不阻碍合同、纯计算和前端工作，但必须有可用 PostgreSQL/Redis 与 Docker 测试环境，才能完成迁移/集成/E2E 验收。
- 微信工具调试需要已安装的开发者工具、可用项目配置与后端；真实 AppID、成员权限及真机验收条件单独记录，不提交真实密钥或机器专用配置。
- 分支沿用 `task/T10-xx-short-name`，只包含该任务相关变更；已有未跟踪效果图、分析文件和本地 `project.config.json` 不自动覆盖或提交。

## 3. 逐任务工作定义

### T10-01 固化字段、计价映射、状态和 API 合同

- 输入：最终方案、另窗已确认业务规则、计价表 Sheet1!A1:C50、7 张 v2 图。
- 工作：为 10 个标准项、组合子行及自定义项定义稳定编码；记录价表原文/原单位/来源单元格与采用的简化规则。明确窗面积转换、屋面输入、灯具组合、缺失工程量处理；不把未定义系数补成 1。定义金额/数量上限、单位、精度、错误码、状态机、权限、幂等及并发字段。
- 输出：受控接口及字段合同、价表映射、权限矩阵、包含完整/缺量/自定义项/报价调整的测试 fixture 规范；按仓库流程更新受影响的后端合同及登记，不修改历史签署内容冒充原基线。
- 验收：AC-01～05、AC-08～10 的合同无未定义字段；已知与待后台补齐的数据分开标注。生产地区价格由预算负责人核定，测试数据不能自动发布。

### T10-02 数据模型、迁移与旧预算兼容

- 输入：01 的模型/版本/精度合同。
- 工作：新增地区、项目录/选项、价格版本、预算修订与明细、保存关系、报价版本和审计所需结构；外键或等效约束、唯一键、查询索引、预期版本字段；旧记录标记 `LEGACY_RANGE`。
- 输出：新增 Flyway 迁移、空库/已有库 fixture、升级和前向恢复说明；不重写已发布迁移。
- 验收：AC-22、25、29、32；旧上下限不变，新字段精度正确，重复迁移不重复数据，失败可以恢复；不能靠清空用户数据通过测试。

### T10-03 设计项目结构化预算参数

- 输入：01 字段合同、02 数据结构、现有 `requirementInputs`。
- 工作：保存/读取地区、占地面积、层数、建筑面积、屋顶面积和可用工程量；导入优先级、推导、人工覆盖、恢复来源、与设计版本绑定；旧项目缺字段明确返回待补信息。
- 输出：参数归一化与导入服务、App 参数接口、设计项目写入适配及测试。
- 验收：AC-02～04、24；有实际建筑面积不覆盖，缺少面宽或进深不推导占地面积，修改来源可追溯，跨项目版本拒绝。

### T10-04 地区、目录及价格 API

- 输入：01 标准项/自定义项与价格合同、02 数据结构。
- 工作：管理地区、标准选项、自定义模板、组合方案及用户可选标记；价格草稿校验与发布、无重叠有效期、启停、按地区查询。
- 输出：Admin 配置 API、App 可用选项 API、带来源的初始配置草稿、权限和发布测试。
- 验收：AC-01、05～07、11～12、24；标准项不能删除，自定义模板可增停，缺价选项不能误作可正常计价的已发布选项；不返回内部价表。

### T10-05 分项计算与完整性校验

- 输入：03 参数、04 选项/价格快照。
- 工作：按单价 × 数量逐子行舍入；组合项汇总；自定义项统一计算；缺价、缺量、免费、明确排除分别处理；后端重算，不信任客户端金额。
- 输出：独立可测试的计算服务、标准/自定义/缺失输入金样、金额边界测试。
- 验收：AC-08～10、13～17、24；全部金样精确到分相等，缺少任一已选项目的价格或数量不返回完整预算总额。

### T10-06 预算生成、保存、历史与公开 DTO

- 输入：05 计算结果、01 状态/接口合同。
- 工作：生成不可变快照、幂等保存到项目列表、按 ID 获取、按项目分页列表；完整/不完整/旧版区间分支；分离 App 与 Admin DTO；原内存依赖迁移。
- 输出：预算创建/保存/查询 API 与 HTTP 合同测试。
- 验收：AC-18、22～26、29；重启小程序后按 ID 恢复同一结果，重复保存只一条；小程序响应不含内部字段，旧历史不漂移。

### T10-07 项目自定义补项与预算修订 API

- 输入：06 预算快照和保存合同、04 自定义模板。
- 工作：从预算建立工作草稿，添加公共模板或项目临时项，补量补价、移除草稿补项、另存模板；已保存修订不可改写，保存生成新版本；带预期版本的并发保护。
- 输出：预算修订与补项 API、明细/合计/审计同事务写入、自动化测试。
- 验收：AC-11～17、22、25～27；临时项不影响其他项目，模板不追溯计入旧预算；重复提交不重复收费，未知价格保持待补，不被当作 0。

### T10-08 最终报价调整、发布及审计 API

- 输入：T10-07 完整预算修订，以及 AC-08～10 对应的金额合同。
- 工作：报价草稿绑定预算修订，支持输入最终价或差额，记录原因；发布前完整性、权限、预期版本校验；改预算后旧草稿失效待复核；发布版本不可变，提供项目已发布报价查询。
- 输出：报价 API、状态转换/审计/并发测试、公开报价 DTO。
- 验收：AC-19～25、27；不得覆盖系统计算总额，草稿不对外，发布后调整新建版本；项目补项不能既进明细又作为差额计入。

### T10-09 后台地区/预算项/价格配置

- 输入：04 Admin API 与现有 `管理后台/src/views/zs/` UI 体系。
- 工作：预算菜单、地区列表、标准/自定义目录、选项与组合方案编辑、地区价格草稿/校验/发布；模板可选范围和启停；错误、空态、权限反馈。
- 输出：Vue 页面、`src/api/zs/` 封装、路由与权限接入、关键表单测试。
- 验收：AC-05～07、11～12、24、30；管理员不写代码即可增自定义模板和地区价；不允许按“保存”隐式发布生产价格。

### T10-10 后台预算详情、补项补价补量

- 输入：07 API、09 模板选择能力。
- 工作：项目预算查询、参数来源和精确金额、缺价/缺量待办；临时项表单、模板选择、补量/专用价、保存修订、另存模板、草稿移除；汇总实时预览但以服务端保存结果为准。
- 输出：预算详情页及补项表单、历史修订对比、组件/API 测试。
- 验收：AC-11～18、22、25、30；完整执行“未知价格先存草稿—补价—分类/总额更新”；同名不同项显示来源而非自动合并。

### T10-11 后台报价预览、调整与发布

- 输入：08 报价 API、10 预算详情。
- 工作：最终报价或差额编辑、原因、对外预览、发布确认、版本历史和并发冲突处理；预览不显示内部成本字段。
- 输出：报价管理页面、权限态/表单/发布测试。
- 验收：AC-19～25、27、30；预览金额与发布后业主读到的版本一致，缺项不能发布，无权限无法调整，已发布记录只读。

## 6. 三端 E2E 最小业务路径

1. 以有权限管理员创建测试地区、标准选项、有效价格版本，显式发布。
2. 小程序所属用户选择测试设计项目，导入并修改/恢复参数，选择主体与外装方案。
3. 创建并保存预算，按ID重读，断言所有分项与系统总额。
4. 管理员建可复用自定义模板，验证默认未向用户开放；显式开放后只影响新选择。
5. 在当前项目添加临时预算项，先保留缺价状态、断言禁止发布，再补价补量并保存修订。
6. 输入最终报价并发布，用户读取同一发布版本；断言自定义项、分类合计、差额与最终金额。
7. 新价格版本生效后重新测算，新预算采用新价，旧预算与已发布报价保持不变。
8. 用另一用户、只读管理员和陈旧预期版本重复关键请求，断言拒绝及无多余写入。
9. 同一幂等键重复生成、补项、发布，断言没有重复项目费用或报价记录。

测试隔离使用专用测试用户/项目/地区ID，只清理该次测试明确创建的数据；不得清空共享开发数据库。

## 7. 视觉验收方法

### 7.1 微信开发者工具必须实操

按“电脑”技能的指导操作微信开发者工具：导入实际小程序项目、编译、打开页面、点击/输入/返回、检查控制台和请求、保存截图。不能用浏览器模拟页面或静态效果图代替工具内运行。

每份证据登记提交、页面、数据fixture、视口逻辑尺寸、像素比、缩放、开发工具版本、基础库、系统字体与截图时间。真机型号与系统版本另外登记，至少覆盖一台iOS和一台Android；无真机条件时该项保持待验收。

### 7.2 对照范围与通过条件

- 标准7页：在与参考图比例一致的固定基准视口比对导航、内容宽度、卡片位置/圆角、行高、字体、颜色、图标、插画、分隔线和底部按钮。按画布宽度统一缩放，不拉伸图片掩盖差异。
- 工程目标：主要卡片边界和按钮位置在基准视口偏差不超过2个逻辑像素；字号/字重、主色和资源逐项记录。系统胶囊、状态栏、抗锯齿和真实金额差异单独标注，不能掩盖业务布局差异。
- 自定义/长名称/不完整/调整报价为新增状态：复用同一组件规范，另建验收截图；原7张图未定义的状态不声称已“逐像素复刻”。
- 检查窄屏和长列表滚动、底部安全区、键盘弹起、禁用/加载/错误状态；金额和操作按钮不能被遮挡。
- 明细只显示费用名称、配置和金额；合计包含全部生效自定义项。无补充项时不出现空的“补充预算项”卡片。
- 7页差异清单全部闭环才通过标准页验收；1:1是同视口还原目标，不以一句“看起来相似”代替记录。

管理端原独立效果图尚未在仓内完整归档，先复用当前管理端设计体系，登记新增页面/弹窗的验收截图；不宣称其已有逐像素参考。
