## 3. 安全与重复执行

- 默认拒绝向非 loopback 地址执行写入型 E2E；远程隔离环境必须显式确认。
- 每次使用唯一 Stub code、幂等键、Runtime 事件 ID 和业务备注。
- Runtime fixture 只能写入配置的对象存储根目录，路径逃逸会立即失败；结束时逐文件删除。
- 不用 SQL 删除业务记录；CI 在 `always()` 阶段停止后端并销毁专属 Docker 卷。
- 报告仅记录状态和业务 ID，不记录 token、授权码明文、密码或下载票据。
